# Mehrnoush Safari - Portfolio Website

A modern, responsive portfolio website built with React for Mehrnoush Safari, UX/UI Designer based in Brussels, Belgium.

## Features

- Single Page Application (SPA) with React Router
- Responsive design for desktop and mobile
- Smooth page transitions and hover animations
- Clean, minimal aesthetic matching the original UXfolio design
- Pages: Home, About, Projects

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Opens the app at [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
npm run build
```

Builds the app into the `build` folder, optimized for production.

## Tech Stack

- React 18
- React Router v6
- CSS (custom, no frameworks)
- Google Fonts (Outfit, Poppins)

## Deployment

This project can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting service. For GitHub Pages, use the `HashRouter` (already configured).
